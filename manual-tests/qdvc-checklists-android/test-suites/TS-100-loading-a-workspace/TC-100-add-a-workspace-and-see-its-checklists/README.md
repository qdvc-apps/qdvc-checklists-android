## Add a workspace and see its checklists

Granting a Studio workspace folder is enough to see its checklists, with no further setup.

#### Preconditions

- A QDVC Checklist Studio workspace folder is on the device, holding at least two checklists
- The app is installed with no workspace added yet, or every workspace has been removed
