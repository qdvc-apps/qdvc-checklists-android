# Creating and editing checklists

Creating checklists, items and headings; editing them; and rearranging items by
dragging.

Every case here changes the workspace on disk. Suite TS-104 checks what those
changes look like as files; this suite checks what the app does and shows.

Two cases cover a defect where creating or editing an item made the whole
checklist vanish and reappear on Home as a checklist of its own.
