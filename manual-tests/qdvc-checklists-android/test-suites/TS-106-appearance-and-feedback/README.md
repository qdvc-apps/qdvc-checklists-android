# Appearance and feedback

Themes, and the tactile feedback the app gives as you use it.

The haptic cases are subjective by nature, but they are worth executing: they are
the fastest way to notice a control that has been wired up without feedback while
everything around it has one. All of them depend on the device's own touch-feedback
setting being on.
