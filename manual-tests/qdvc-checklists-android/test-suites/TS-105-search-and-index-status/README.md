# Search and index status

Finding a checklist by its text, and the page that reports what the app has
indexed.

Search covers a checklist's name, description and the text of its items. It
searches the app's own copy of the workspace, so a checklist added outside the app
is not findable until the next launch or **Regenerate now**.
