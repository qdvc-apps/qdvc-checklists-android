# Moving around the app

Getting to a checklist, switching between the ones you have open, and coming back
to where you were.

Several cases here cover defects found during development: a newly created
checklist opening the wrong one, and lists losing their scroll position when a tab
is left. Those are the ones marked `Regression`.
