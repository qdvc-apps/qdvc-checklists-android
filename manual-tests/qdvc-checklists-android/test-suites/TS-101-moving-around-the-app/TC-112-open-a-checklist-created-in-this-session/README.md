## Open a checklist created in this session

A checklist created since the app launched must open like any other. This
previously opened a different, existing checklist instead, and only came right
after a restart.

#### Preconditions

- A workspace with at least two existing checklists is added
- At least one of those checklists has been opened, so it appears in Jump
